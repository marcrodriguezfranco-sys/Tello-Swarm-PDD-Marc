   5 ## What this project does
   6
   7 Autonomous drone search-and-land system for the DJI Tello (RoboMaster TT). The operator selects a target object
     using the laptop webcam + YOLOv8, then the drone takes off, searches by rotating, identifies the same object wit
     h its onboard camera, approaches it, and lands.
   8
   9 ## Running the application
  10
  11 ```bash
  12 # Connect the PC to the Tello's WiFi hotspot first, then:
  13 python main.py
  14 ```
  15
  16 There is no package manager file (no `requirements.txt` / `pyproject.toml`). Install dependencies manually:
  17
  18 ```bash
  19 pip install djitellopy ultralytics opencv-python
  20 ```
  21
  22 Model weights `yolov8n.pt` must be present in the project root (downloaded automatically by ultralytics on first
      use if absent). `yolov5s.pt` is present on disk but is not used by any current script.
  23
  24 ## Architecture
  25
  26 ```
  27 main.py          ← tkinter GUI, entry point
  28   ├─ detection.py   ← object selection via laptop webcam (YOLOv8, VideoCapture(0))
  29   └─ mission_v2.py  ← active mission loop run on the drone's camera feed
  30 ```
  31
  32 **Selection phase** (`detection.py`): opens the laptop camera, runs YOLOv8 inference frame-by-frame, and returns
      a `class_id` only after the same class appears in **50 consecutive frames** (`CONFIRMATION_FRAMES`). `person` i
     s excluded. Closes automatically on confirmation or when the user presses `q`/`ESC`.
  33
  34 **Mission phase** (`mission_v2.py`): two-thread design.
  35 - *Movement thread*: rotates ±30° left/right then moves forward 75 cm when no target is detected.
  36 - *Main thread*: reads frames from `tello.get_frame_read()`, runs YOLOv8, draws bounding boxes, writes video if
     recording is enabled. Lands immediately on first detection of the target `class_id`.
  37
  38 **GUI threading** (`main.py`): each blocking operation (connect, takeoff, land, detection, mission) runs in a `d
     aemon=True` thread so the tkinter event loop is never blocked. Battery is polled every 10 s in its own thread.
